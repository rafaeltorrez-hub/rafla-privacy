Política de privacidad de Ra/Fla

Última actualización: 5 de noviembre de 2026

1. Responsable y contacto

Ra/Fla es una aplicación orientada a proporcionar información, herramientas y servicios relacionados con el mantenimiento automotriz. El responsable de la aplicación y del tratamiento de los datos personales es Rafael Augusto Torrez Galdamez.

Para consultas relacionadas con esta política, solicitudes de acceso, corrección o eliminación de datos personales, puedes comunicarte a: rafaeltorrez499@gmail.com.

País de contacto del responsable: Estados Unidos. No se publica una dirección postal en esta política.

2. Información que puede recopilarse

La información recopilada depende de las funciones que estén disponibles y que el usuario decida utilizar. Puede incluir:

  • Datos del vehículo: marca, modelo, año, motor, transmisión, número de identificación del vehículo (VIN), kilometraje, códigos OBD-II, síntomas, reparaciones y registros de mantenimiento introducidos por el usuario.
  • Contenido del usuario: preguntas, comentarios, notas y fotografías de vehículos o piezas que el usuario decida enviar, cuando esas funciones estén disponibles.
  • Datos de cuenta y contacto: nombre, dirección de correo electrónico y preferencias, si la aplicación ofrece registro de cuenta y solicita esos datos.
  • Ubicación: ubicación aproximada o precisa únicamente si una función requiere esos datos y el usuario concede el permiso correspondiente.
  • Datos profesionales: especialidades y datos de contacto de mecánicos o talleres que decidan crear un perfil, si el directorio profesional está habilitado.
  • Datos técnicos: información básica del dispositivo, registros de errores y datos de funcionamiento, si se habilitan herramientas de diagnóstico técnico o analítica.
  • Datos de compras: información necesaria para procesar pagos o compras, únicamente si esas funciones se incorporan. Los datos de pago podrán ser procesados por el proveedor correspondiente.

Ra/Fla no debe solicitar información personal que no sea necesaria para proporcionar una función solicitada por el usuario.

3. Cómo utilizamos la información

La información podrá utilizarse para las siguientes finalidades, cuando las funciones correspondientes estén disponibles:

  • Guardar y mostrar información de vehículos.
  • Organizar historiales de mantenimiento y recordatorios.
  • Responder preguntas relacionadas con mantenimiento automotriz.
  • Ofrecer orientación técnica y ayudar a interpretar códigos de diagnóstico.
  • Facilitar la búsqueda y compatibilidad de piezas automotrices.
  • Facilitar el contacto entre usuarios, talleres y mecánicos.
  • Mejorar el funcionamiento, estabilidad y seguridad de la aplicación.
  • Atender solicitudes de los usuarios.
  • Prevenir usos fraudulentos o actividades no autorizadas.
  • Cumplir las obligaciones legales aplicables.

4. Asistente automático e inteligencia artificial

Si Ra/Fla incorpora un asistente de inteligencia artificial, las preguntas y los datos del vehículo que el usuario decida enviar podrán ser transmitidos al proveedor tecnológico integrado para generar respuestas u orientación técnica.

La información transmitida dependerá de los datos que el usuario decida proporcionar y de las funciones que estén habilitadas. Antes de activar un servicio de este tipo, se deberá informar adecuadamente sobre el proveedor y el tratamiento de la información.

Las respuestas automáticas pueden contener errores o estar incompletas. No sustituyen una inspección física del vehículo, un diagnóstico profesional ni los procedimientos oficiales del fabricante.

Para trabajos relacionados con frenos, dirección, airbags, combustible, sistemas eléctricos de alto voltaje u otros componentes críticos, se recomienda acudir a personal cualificado.

5. Compartición de información con terceros

Ra/Fla no vende deliberadamente información personal de sus usuarios.

Cuando las funciones correspondientes estén habilitadas, determinados datos podrán compartirse con proveedores tecnológicos que presten servicios necesarios para el funcionamiento de la aplicación, como alojamiento, procesamiento de información, comunicaciones, mapas, seguridad, analítica o procesamiento de pagos.

Estos proveedores deberán utilizar la información únicamente para prestar los servicios contratados y conforme a las condiciones y obligaciones de privacidad aplicables.

Si un usuario decide compartir información con un taller o mecánico, ese destinatario recibirá los datos que el usuario haya autorizado compartir. El destinatario podrá tratar esa información conforme a sus propias obligaciones y políticas de privacidad.

También podrá divulgarse información cuando sea necesario para cumplir una obligación legal, atender una solicitud válida de una autoridad o proteger los derechos y la seguridad de los usuarios.

6. Ubicación y servicios móviles

Las funciones que requieran ubicación deberán solicitar el permiso correspondiente y explicar por qué necesitan esa información.

El usuario puede denegar o retirar los permisos de ubicación desde los ajustes de su dispositivo. Algunas funciones podrían dejar de estar disponibles si necesitan esos permisos.

Si se incorpora una función de ubicación en tiempo real para mecánicos, la ubicación deberá compartirse con autorización, para un servicio aceptado y durante el tiempo necesario para prestarlo.

La ubicación de un mecánico no deberá hacerse pública por defecto.

7. Conservación y eliminación de datos

Los datos personales se conservarán únicamente durante el tiempo necesario para cumplir las finalidades descritas en esta política, atender las solicitudes de los usuarios y cumplir las obligaciones legales aplicables.

El usuario podrá solicitar acceso, corrección o eliminación de su información personal escribiendo a: rafaeltorrez499@gmail.com.

Las solicitudes serán revisadas y atendidas conforme a las leyes aplicables. Algunos datos podrán conservarse durante el tiempo necesario para cumplir obligaciones legales o resolver controversias.

Si una versión de la aplicación almacena información únicamente en el dispositivo, esos datos podrían perderse al borrar los datos de la aplicación o cambiar de dispositivo. El almacenamiento local no significa que exista una copia sincronizada en la nube.

8. Seguridad de la información

Ra/Fla deberá aplicar medidas técnicas y organizativas razonables para proteger la información contra pérdida, acceso no autorizado, alteración, divulgación o uso indebido.

Estas medidas podrán incluir controles de acceso, permisos limitados, protección de comunicaciones, actualizaciones de seguridad y procedimientos para atender incidentes.

Ningún sistema de almacenamiento o transmisión de información puede garantizar seguridad absoluta.

9. Privacidad de menores de edad

Ra/Fla está orientada a personas interesadas en información y servicios relacionados con el mantenimiento automotriz.

La aplicación no está diseñada para solicitar deliberadamente información personal de menores de edad sin las autorizaciones que exijan las leyes aplicables.

Si se identifica que se han recopilado datos personales de un menor de manera no permitida, se tomarán las medidas correspondientes para revisar y eliminar esa información cuando proceda.

10. Enlaces y servicios externos

La aplicación puede incluir enlaces a sitios web de fabricantes, proveedores de piezas, talleres u otros servicios externos.

Al acceder a esos sitios, el usuario estará sujeto a las políticas y condiciones del tercero correspondiente. Ra/Fla no controla las prácticas de privacidad de sitios externos.

Si en el futuro se incorporan enlaces de afiliados o relaciones comerciales, se informará de ello de manera clara cuando corresponda.

11. Transferencias internacionales de información

Algunos proveedores tecnológicos pueden procesar o almacenar información en países distintos del país de residencia del usuario o del responsable de la aplicación.

Cuando se realicen esas transferencias, deberán aplicarse las medidas y salvaguardas exigidas por las leyes de protección de datos correspondientes.

12. Derechos y opciones del usuario

Dependiendo del lugar de residencia y de las leyes aplicables, el usuario puede tener derecho a solicitar acceso, corrección, eliminación, limitación u oposición al tratamiento de sus datos personales, así como otros derechos reconocidos por la legislación.

Para ejercer estos derechos, puedes escribir a: rafaeltorrez499@gmail.com.

El usuario también puede retirar los permisos de cámara, ubicación u otros permisos desde los ajustes de su dispositivo. Al hacerlo, algunas funciones de la aplicación podrían dejar de funcionar correctamente.

13. Cambios en esta política

Esta política podrá actualizarse cuando cambien las funciones de Ra/Fla, los proveedores tecnológicos, las prácticas de tratamiento de datos o los requisitos legales aplicables.

La versión actualizada se publicará en esta misma dirección y mostrará la fecha de su última actualización.

Cuando los cambios sean importantes, se informará a los usuarios por los medios disponibles y cuando así lo exija la legislación.
